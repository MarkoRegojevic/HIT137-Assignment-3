# Outline of the game 

This Project is an image puzzle game. The program allowes the user to load an image and turn it into a puzzle using a 3x3, 4x4 or 5x5 grid. The puzzle tiles can be swapped, rotated and flipped, and the aim is to return every tile to its correct position and orientation. 

 # Requirements 
The following Python libraries are required:

- OpenCV
- Pillow
- NumPy
- Tkinter
